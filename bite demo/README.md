# Bite — Demo Website

Demo statis Bite untuk GitHub Pages.

## Catatan
- Versi ini menggunakan data menu statis dari `js/menu-data.json`.
- Keranjang dan alur konfirmasi hanya simulasi di browser.
- Tidak ada pesanan, pembayaran, login admin, atau perubahan database yang benar-benar diproses.
- Versi PHP/MySQL asli tidak diubah; file backend dan dump database tidak disertakan di repository demo.

## Menjalankan lokal
Buka `index.html` melalui browser atau gunakan Live Server di Visual Studio Code.

## GitHub Pages
Atur repository ke **Settings → Pages → Deploy from a branch → main → /(root)**.
